Dynamic NoSQL to Relational SQL Engine

Convert Nested NoSQL JSON into Normalized SQL Databases On The Fly

Say goodbye to manual schema crafting. SQLify dynamically inspects arbitrary JSON, flattens composite structures, normalizes 1:N arrays into relational child tables, and produces ready-to-query SQLite databases.

SQLify — Desktop Application (PySide6)
Core Capabilities

Engineered for Automated Data Engineering

Everything you need to transform semi-structured, nested payloads into high-integrity relational schemas with zero manual DDL writing.

Dynamic Schema Inference

Automatically scans root keys, detects primitive types (`INTEGER`, `REAL`, `TEXT`), and generates optimal DDL `CREATE TABLE` queries with primary keys and constraints.

1:N Array Normalization

Embedded lists and array collections (e.g. `orders[]`, `phones[]`, `courses[]`) are decoupled into relational child tables linked back via foreign keys with `CASCADE DELETE`.

Smart Object Flattening

Composite JSON objects are flattened hierarchically (`address.city` → `address_city`), ensuring 1NF compliance while retaining clear lineage and context.

Dark Glassmorphic GUI

Crafted with PySide6 (Qt6), featuring custom QSS styling, animated telemetry gauges, searchable tree hierarchies, and drag-and-drop file ingestion.

Configurable Type Rules

Customize SQL datatype mappings easily via `config/type_mapping.json` to suit custom database dialect preferences or strict validation requirements.

Native SQLite Integration

Directly generates SQLite `.db` binary files, populates normalized rows in real-time, and provides interactive sorting, filtering, and schema exploration.

        Developer Guide
        
Run SQLify in Seconds

        

          SQLify is built with standard Python and PySide6. Follow these quick steps to get up and running.
        

      


      

        

          
          
# 1. Clone the repository

          git clone https://github.com/sumitimran1/sqlify.git
cd sqlify


          
# 2. Set up virtual environment and install PySide6

          python -m venv .venv
# On Windows: .\.venv\Scripts\activate
# On Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt


          
# 3. Launch the application

          python app.py
